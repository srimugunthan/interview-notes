# UI Frontend Tutorial

A hands-on tutorial series matching [syllabus.md](../syllabus.md) — the minimal, high-leverage path to being productive building real apps with AI assistance.

Each chapter is meant to be read *with a code editor open*. Don't just read the snippets — type them out, break them, and see what happens. That's where the actual learning happens; reading alone won't build the debugging instinct you need.

## Chapters

1. [HTML & CSS Essentials](./01-html-css.md) — semantic tags, forms, accessibility, Flexbox, Grid
2. [JavaScript Core](./02-javascript-core.md) — variables, functions, async/await, the DOM, closures, `this`
3. [React Fundamentals](./03-react.md) — components, props, state, effects, a full fetch-based app
4. [Tooling Literacy](./04-tooling.md) — npm, bundlers, browser DevTools
5. [Code Review Skill for the AI Era](./05-code-review.md) — reading and critiquing AI-generated components

## How to use these

- Each chapter ends with a **"Try it"** section — do these before moving on.
- You need only a text editor and a browser for Chapters 1–2. Chapter 3 onward assumes Node.js and npm are installed (`node -v` should print something ≥ 18).
- Total time budget per the syllabus: ~6-8 weeks of focused work, part-time.
